Configurar Fonte de Dados
Para ver dados reais, o GitHub Actions tem de estar configurado e a correr. Segue os passos abaixo.
Cria uma conta em github.com e um repositório público chamado perf-benchmark
Obtém a tua chave da PageSpeed API em console.cloud.google.com → APIs → PageSpeed Insights API → Credenciais
No GitHub, vai a Settings → Secrets → Actions → New secret. Chama-lhe PAGESPEED_API_KEY e cola a chave
Faz upload dos ficheiros scripts/run-benchmark.js e .github/workflows/daily-benchmark.yml para o repositório
Vai a Actions → Daily Performance Benchmark → Run workflow para correr manualmente a primeira vez
Cola abaixo o URL do teu repositório GitHub (para carregarmos os dados)
